### **Extraction Rules**
1. **Construction Status Heading** --> Bolded heading in the text columns. If missing, enter "UNK". 

2. **Fuel Type Heading** --> Italicized heading in the text columns. If missing, enter "UNK". 

3. **Pipeline Company Name** --> The company name is sometimes found in the first line of the paragraph, but not always. Sometimes, the pipeline company name is mentioned as a shorthand in the possessive form (e.g., "Sun's" or "Stanolind's"). This is usually bolded, though not always. There are sometimes multiple companies; if this is the case then separate the names with a semicolon followed by a space. Only include the primary pipeline companies with ownership over the project. Ignore any mentions of contractors or construction company. 

4. **Fuel Type Raw** --> The type of fuel which is explicitly described in the heading. If the heading cannot be found, enter "UNK". *Do not* infer fuel type in this entry.  

5. **Fuel Type Inferred** --> If the Fuel Type Raw is *not* "UNK", then directly copy the entry from Fuel Type Raw. Otherwise, if the Fuel Type Raw was "UNK", please try to infer the fuel type. Please use contextual clues as well as knowledge about the company, including the company name and other publicly available information about any commodities the company specializes in. **However, if there is any uncertainty about the fuel type, please write "UNK"**, because the accuracy of the fuel type is very important. **Do not make up any information.** If you must infer based on historical knowledge of the company, **be sure not to confuse similar-sounding company names.** You may also use volumetric units to infer fuel type (for instance, "barrel" would allow you to infer that the fuel is liquid). 

6. **Construction Complete** --> A boolean indicator on whether the construction is complete. Reference **Construction Status Heading** if present. Otherwise, you may infer this using verbs and other context clues. For instance, this is true if the company "completed", "laid", or "installed" the pipeline (though other similar verbs may also be used). This is false if, for example, the entry indicates the company "proposed", "is building", "is constructing", "abandoned", "held", or paused the pipeline (though other verbs may also be used). 

7. **Total Pipeline Length** --> The total mileage of the pipeline, which is described explicitly in almost every paragraph. May be written in the pdf as a string, integer, fraction, or decimal in the paragraph. (However, please convert the output to integer or decimal format; do not output fractions). If this information cannot be found, write "UNK". 

8. **Pipeline Diameter** --> The diameter of the pipeline in inches, if provided. If the paragraph describes multiple sections with different diameters, list all the diameters separated by a semicolon followed by a space. This is not described for all pipelines; if diameter data is missing for a segment, write "UNK" (but capture as much diameter data as possible). Your output should be numeric values. If diameter is only given as a range, write the range in the format "X to Y" (for numeric values X and Y). 

9. **Pipeline Length by Diameter** --> If there are multiple pipeline diameters specified, we would like a separate mileage corresponding to each diameter. Multiple mileages should be separated with a semicolon followed by a space, and the listed order should match the order of the corresponding diameter. However, if there are any segments of unknown length, write "UNK". If there is only a single constant pipeline diameter, or the diameter is not given, this value should be equal to the total pipeline length. 

10. **Origin City** --> The city in which the pipeline originates. This is not described for all paragraphs (oftentimes, either the city or county will be named but not both). If it is not explicitly named, *do not infer this*, but write "UNK". The Origin City should be a valid U.S. city or town. 

11. **Terminus City** --> The city in which the pipeline terminates. This is not described for all paragraphs (oftentimes, either the city or county will be named but not both). If it is not explicitly named, *do not infer this*, but write "UNK". The Terminus City should be a valid U.S. city or town. 

12. **Origin County** --> The county in which the pipeline originates. This is not described for all paragraphs (oftentimes, either the city or county will be named but not both). If it is not explicitly named, *do not infer this*, but write "UNK". The Origin County should be a valid U.S. county. 

13. **Terminus County** --> The county in which the pipeline terminates. This is not described for all paragraphs (oftentimes, either the city or county will be named but not both). If it is not explicitly named, *do not infer this*, but write "UNK". The Terminus County should be a valid U.S. county. 

14. **Other Origin Information** --> Optional variable to track other miscellaneous information related to the origin of the pipeline. For instance, the paragraph may mention the name or geographic region of gas field, oil field, tank farm, pump station or other point of reference, which should be recorded for this variable (including the type of location - e.g., field, tank farm, station). If other origin information is not described in the paragraph besides the origin state, city, or county, simply write "NA". 

15. **Other Terminus Information** --> Optional variable to track other miscellaneous information related to the terminus of the pipeline. For instance, the paragraph may mention the name or geographic region of gas field, oil field, tank farm, pump station or other point of reference, which should be recorded for this variable (including the type of location - e.g., field, tank farm, station). If other terminus information is not described in the paragraph besides the terminus state, city, or county, simply write "NA". 

16. **Origin State** --> The state of the pipeline origin. This is often described explicitly in the paragraph, but may sometimes need to be inferred from the origin city, origin county, or other origin descriptions. If this information cannot be determined, enter "UNK". 

17. **Terminus State** --> The state of the pipeline terminus. This is often described explicitly in the paragraph, but may sometimes need to be inferred from the terminus city, terminus county, or other terminus descriptions. If this information cannot be determined, enter "UNK". 

18. **Interstate or Intrastate** --> Whether the pipeline is interstate or intrastate. This must be inferred from the origin state and terminus state, because it is never explicitly stated in the text. **VERY important considerations: If a paragraph mentions that a pipeline segment is part of a larger interstate line, then the segment should be coded as interstate, even if the segment starts and ends strictly within a single state.** If there is one segment that is interstate and one segment that is intrastate, the entire pipeline should be considered interstate. If the pipeline project is a loop connected to a larger, interstate pipeline, the loop segment should be considered interstate, even if the loop starts and ends strictly within one state. 

19. **New Construction** --> True if the project constructs a new line, False otherwise. New construction is often implied by verbs such as, but not limited to, "constructed", "completed", "constructing", "laid", or "installed" lines. You may generally infer that the construction is new unless otherwise indicated by terminology such as "reversed", "converted", "reconditioned", or other language indicating a modification of an existing pipeline.

20. **Parallel or Loop** --> Whether it is indicated that the pipeline is constructed in parallel to an existing line, or that the line is a "loop"/"being looped"/"looping", which is the same thing. 

21. **Function** --> The function type of the pipeline, such as transmission, distribution, gathering, fielding, or other. Oftentimes this is not explicitly described by the paragraph, in which case you should write "UNK". Do not infer this if it is not explicitly stated. 

22. **Connection** --> Whether it is indicated that the project is a connection or extension to an existing pipeline. 

23. **FPC** --> Whether the FPC is mentioned in relation to the project.
